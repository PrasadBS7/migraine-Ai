# MigraineAI Pro

AI-powered migraine prediction and clinical decision-support prototype —
built as a final-year ECE project. Combines a live symptom/vitals dashboard,
trigger tracking, and two machine-learning pipelines (tabular classification
+ time-series forecasting) to estimate migraine onset risk.

> ⚠️ **Disclaimer:** This is an academic prototype, not a certified medical
> device. It does not replace diagnosis or treatment by a qualified
> neurologist or healthcare professional. Datasets used for training are
> synthetic unless otherwise noted.
